# Event Discovery & RSVP Platform

A responsive event discovery and RSVP platform designed to help students discover campus events, view event details, and RSVP to events.

## Features

- Browse campus events
- View event details
- RSVP to events
- Event categories
- Event reminders
- Responsive, mobile-first interface
- Local data persistence using localStorage

## Technologies Used

- HTML
- CSS
- JavaScript
- Figma

## How It Works

Users can browse available events, select an event to view its details, and RSVP to events they are interested in attending.

The platform uses localStorage to persist relevant user and event data on the client side.
